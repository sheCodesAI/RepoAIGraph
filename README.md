# RepoGraph AI

> **Understand how a GitHub repository works — not just where its files are.**

RepoGraph AI transforms a public GitHub repository into an interactive **Neo4j-powered knowledge graph**.

Instead of manually navigating hundreds of folders and files, developers can paste a GitHub URL and explore how repositories, files, functions, APIs, technologies, features, dependencies, and data flows are connected.

---

## 🚀 Overview

Modern GitHub repositories can contain hundreds or thousands of files.

Finding a file is easy.

Understanding **how the entire project is connected** is much harder.

**RepoGraph AI** solves this by analyzing a repository and representing its structure and relationships as a graph using **Neo4j**.

### Basic Flow

```text
GitHub Repository
       ↓
Repository Parser
       ↓
Code & Structure Analysis
       ↓

       ↓

       ↓
Interactive Visualization
       ↓
AI-Powered Explanation
